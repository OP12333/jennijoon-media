Privacy Policy

JenniJoon Uploader · last updated 2026-11-17

JenniJoon Uploader is a personal tool run by the creator Jenni Joon to publish her own videos. Its only user is the owner of the Jenni Joon channel.

Data we access

With the owner's permission the tool uses the YouTube API Services with two scopes: youtube.upload (to upload videos) and youtube.readonly (to read the signed-in channel's name and ID, so it never uploads to the wrong channel). No data of other users is accessed.

How data is stored

The OAuth token is stored only on the owner's own computer. Nothing is sent to any server other than Google/YouTube and Instagram. No data is sold, shared or used for advertising.

YouTube and Google

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access

Access can be revoked at any time at Google security settings → Third-party access. The locally stored token is then deleted.
